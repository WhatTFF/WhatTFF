### Projects

#### [AK820 Screen Studio](https://github.com/WhatTFF/linux-ajazz-ak820-pro-gtk)
> Native Linux control app for the AJAZZ / Epomaker AK820 Pro keyboard screen.
- Written in **Rust & GTK3**.
- Upload custom GIFs, videos, images, and text to the 0.85" 128×128 keyboard screen.
- Automatic clock synchronization and procedural animation support.
- Pre-packaged for RPM, DEB, and AppImage.

#### [Unplug](https://github.com/WhatTFF/Unplug)
> Mindful screen-time management and app lock for Android.
- Built with **Flutter & Dart**.
- Helps build intentional digital habits with friction-based blockers (wait or write).
- Completely free, open source, and offline without user tracking or accounts.

#### [linux-ajazz-ak820-pro-app](https://github.com/WhatTFF/linux-ajazz-ak820-pro-app) (Deprecated)
> Previous Rust & Tauri companion app for the AK820 Pro keyboard screen.
- Development stopped. Superseded by the native GTK3 version ([AK820 Screen Studio](https://github.com/WhatTFF/linux-ajazz-ak820-pro-gtk)).
